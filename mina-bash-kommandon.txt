pwd - visar vilken mapp jag befinner mig i.

ls - visar filer och mapper i den aktuella mappen. 

cd - används för att navigera mellan mappar.

mkdir - skapar en ny mapp. 

touch - skapar en ny fil. 

cat -visar innehållet i en textfil

push - Skickar förändring från den lokala mappen till en 
        repository från en lokal mapp
       
pull - Tar förändringar till dina lokala mapp för att inspekteras 
        samt använda i en utvecklingsmiljö

git commit - "Adresserar" vad inneheållet/förändringen inkkluderar.
        Läggs till ett -m (message) om vad som har gjorts

cd .. - För att navigera upp i din mappstruktur

git add . -Adderar till alla ändrade filer i en commit 

git log - visar versionhistorik

git remote add origin - Designerar till GitHub
